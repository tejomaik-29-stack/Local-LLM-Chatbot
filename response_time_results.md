
# Response Time Experiment – Local LLM Chatbot

## 1. Objective

To measure the time taken by the Llama 3.2 1B model to generate answers.

## 2. Experimental Results

| Test | Question | Response Time |
|---|---|---|
| 1 | Artificial Intelligence | 36.86 seconds |
| 2 | Python | 13.84 seconds |
| 3 | Machine Learning | 11.33 seconds |
| 4 | Cloud Computing | 11.06 seconds |
| 5 | Database | 12.56 seconds |

## 3. Average Response Time

Average = Total Response Time / Number of Tests

Average = 85.65 / 5

**Average Response Time = 17.13 seconds**

## 4. Observation

- Fastest response: 11.06 seconds.
- Slowest response: 36.86 seconds.
- All five questions received AI-generated answers.

## 5. Conclusion

The chatbot successfully generated answers using Llama 3.2 1B. The average response time was 17.13 seconds.
